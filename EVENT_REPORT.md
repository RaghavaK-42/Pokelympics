# Pokélympics event report

Each tournament selects 10 distinct events at random from the 18 below. The selection and results are saved for the room. Each Pokémon can enter only one event. Most gold medals wins.

Across the full pool, every stat appears in exactly **8 events** and every type receives a bonus in exactly **3 events**. Event type lists vary from 2 to 4 types. A random ten-event subset may have uneven coverage.

| Event | Important stats | Boosted types | Performance metric |
|---|---|---|---|
| 100 Meter Dash | Speed | Electric, Normal, Fire | Time (lower wins) |
| Shot Put | Defense, Attack | Fighting, Rock, Steel | Distance / height (higher wins) |
| Archery | Special Attack, Special Defense | Grass, Psychic, Dark | Judged points (higher wins) |
| 1500 Meter Run | Speed, HP | Ground, Bug, Dragon | Time (lower wins) |
| 200 Meter Freestyle | HP, Speed, Special Defense | Water, Ice, Flying | Time (lower wins) |
| Long Jump | Attack, Speed, Defense | Flying, Ground, Fighting | Distance / height (higher wins) |
| Floor Gymnastics | Attack, Special Attack, Special Defense | Fairy, Psychic, Ghost | Judged points (higher wins) |
| Weightlifting | Defense, HP | Steel, Rock, Fire | Weight (higher wins) |
| Fencing Target Challenge | Attack, Special Attack | Bug, Dark, Poison | Judged points (higher wins) |
| Balance Beam | Defense, Special Attack, Special Defense, HP | Normal, Grass, Fairy | Judged points (higher wins) |
| 110 Meter Hurdles | HP, Attack, Speed | Normal, Electric, Ground | Time (lower wins) |
| High Jump | Attack, Defense, Speed | Flying, Dragon | Distance / height (higher wins) |
| Javelin Throw | Defense, Special Attack, Special Defense | Fighting, Steel, Poison | Distance / height (higher wins) |
| Discus Throw | Defense, Special Attack, HP | Rock, Fire, Dark | Distance / height (higher wins) |
| Platform Diving | Attack, Special Attack, Special Defense | Water, Psychic, Ghost, Fairy | Judged points (higher wins) |
| Speed Climbing | HP, Defense, Special Defense | Grass, Bug, Poison | Time (lower wins) |
| 500 Meter Speed Skating | Attack, Special Defense, Speed | Ice, Ghost | Time (lower wins) |
| 200 Meter Canoe Sprint | HP, Special Attack, Speed | Water, Electric, Dragon, Ice | Time (lower wins) |

Every event ends with a Pokémon podium and a full ranking with measured performances, relevant star ratings, and type-advantage indicators. PNG animations are driven by the saved results. Formulas stay off the webpage.

Internal scoring retains the sum of relevant star ratings, a single non-stacking 12% bonus if either type matches, and one random 0.9–1.1 performance factor. Metrics preserve exactly the resulting rank order.
